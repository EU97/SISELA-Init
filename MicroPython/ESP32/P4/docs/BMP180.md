# BMP180 — Sensor Digital de Presión Barométrica y Temperatura

## Información general

| Parámetro | Valor |
|-----------|-------|
| **Fabricante** | Bosch Sensortec |
| **Tipo** | MEMS piezoresistivo digital |
| **Interfaz** | I2C (dirección fija 0x77) |
| **Rango de presión** | 300–1100 hPa (30–110 kPa) |
| **Rango de temperatura** | –40 a +85 °C |
| **Resolución presión** | 0.01 hPa (modo ultra-high) |
| **Resolución temperatura** | 0.1 °C |
| **Precisión absoluta** | ±1 hPa (típica) |
| **Alimentación** | 1.8–3.6 V |
| **Consumo** | 5 µA (modo estándar, 1 muestra/s) |
| **Chip ID** | 0x55 (registro 0xD0) |

## Principio de funcionamiento

El BMP180 utiliza un **puente de Wheatstone piezoresistivo** fabricado con tecnología MEMS sobre silicio. La presión atmosférica deforma una membrana microscópica que altera la resistencia de los piezoresistores, generando una señal proporcional a la presión.

El sensor incluye un ADC sigma-delta interno y un procesador que:
1. Mide la señal del puente (proporcional a presión y temperatura)
2. Almacena resultados sin compensar en registros digitales
3. Proporciona 11 coeficientes de calibración de fábrica en EEPROM

## Secuencia de medición

### Temperatura
1. Escribir `0x2E` en registro `0xF4`
2. Esperar 4.5 ms
3. Leer 16 bits de `0xF6`–`0xF7` → **UT** (uncompensated temperature)

### Presión
1. Escribir `0x34 + (oss << 6)` en registro `0xF4`
2. Esperar según modo de sobremuestreo:
   - oss=0: 4.5 ms (ultra-low power)
   - oss=1: 7.5 ms (estándar)
   - oss=2: 13.5 ms (alta resolución)
   - oss=3: 25.5 ms (ultra-alta resolución)
3. Leer 24 bits de `0xF6`–`0xF8`, desplazar >> (8 - oss) → **UP**

## Algoritmo de compensación

### Temperatura

```
X1 = (UT − AC6) × AC5 / 2¹⁵
X2 = MC × 2¹¹ / (X1 + MD)
B5 = X1 + X2
T  = (B5 + 8) / 2⁴          [en 0.1 °C]
```

### Presión

```
B6 = B5 − 4000
X1 = (B2 × (B6² / 2¹²)) / 2¹¹
X2 = AC2 × B6 / 2¹¹
X3 = X1 + X2
B3 = ((AC1 × 4 + X3) << oss + 2) / 4
X1 = AC3 × B6 / 2¹³
X2 = (B1 × (B6² / 2¹²)) / 2¹⁶
X3 = ((X1 + X2) + 2) / 4
B4 = AC4 × (X3 + 32768) / 2¹⁵     [unsigned]
B7 = (UP − B3) × (50000 >> oss)    [unsigned]

if B7 < 0x80000000:
    p = (B7 × 2) / B4
else:
    p = (B7 / B4) × 2

X1 = (p / 2⁸)²
X1 = (X1 × 3038) / 2¹⁶
X2 = (−7357 × p) / 2¹⁶
p  = p + (X1 + X2 + 3791) / 2⁴    [en Pa]
```

## Fórmula de altitud barométrica (ISA)

```
h = 44330 × (1 − (P / P₀)^(1/5.255))   [metros]
```

Donde:
- **P** = presión medida (Pa)
- **P₀** = presión al nivel del mar (Pa)
  - ISA estándar: 101325 Pa = 1013.25 hPa
  - Ajustable al QNH local para altitud real

## Módulo GY-68

El módulo comercial GY-68 incluye:
- BMP180 con regulador LDO (acepta 3.3V o 5V)
- Resistencias de pull-up I2C (4.7 kΩ)
- Capacitor de desacoplamiento
- 4 pines: VCC, GND, SCL, SDA
