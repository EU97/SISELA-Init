# SSD1306 — Ficha técnica breve

- Tipo: Controlador de pantalla OLED monocromo
- Resolución común: 128×64 (también 128×32)
- Interfaz: I2C (también SPI)
- Dirección I2C típica: 0x3C (a veces 0x3D)
- Voltaje: 3.3 V recomendado en ESP32

## Inicialización (resumen práctico)

- `DISPLAYOFF (0xAE)`
- Ajuste de reloj, multiplex (según 64 filas), offset y línea de inicio
- `CHARGEPUMP ON (0x8D, 0x14)`
- Modo de memoria horizontal (0x20, 0x00)
- Remap de segmentos/com escaneo (A1, C8) para orientación estándar
- Contraste, pre-carga, VCOM detect
- `DISPLAYON (0xAF)`

El driver `lib/ssd1306.py` gestiona esta secuencia y provee API tipo `framebuf`:

- `fill(color)`, `pixel(x,y,color)`, `text(str,x,y)`, `line`, `rect`, `fill_rect`, `show()`

## Observaciones

- El búfer ocupa `ancho*alto/8` bytes (para 128×64 → 1024 bytes)
- Para mejor rendimiento, dibuja en RAM (framebuffer) y luego llama a `show()`
- Evita refrescos a >60 Hz. En esta práctica, 2–10 Hz es suficiente
